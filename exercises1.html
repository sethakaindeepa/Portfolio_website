Case 01

This exercise demonstrates CSS positioning techniques by creating a four-section layout with centered shapes and a fixed middle element. It focuses on using relative and absolute positioning to align circles, squares and a central component accurately while maintaining a structured and balanced design.

Case 02

This layout was created using CSS positioning techniques including relative and absolute positioning, along with the CSS box model. The design features a fixed header, vertical sidebar navigation, horizontal top menu, image content section and a footer. Proper spacing, alignment and element placement were controlled using margins, padding, borders and positioning properties to achieve a structured and responsive webpage layout.

Case 03

This exercise demonstrates the use of CSS fixed, relative and absolute positioning to create a centered circular layout. The design features layered borders that remain fixed at the center of the viewport while the inner content flows within the structure. The CSS box model was used to control spacing, alignment and border styling, resulting in a clean, visually balanced component.
